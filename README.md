# Mycro-Tec Biology Battlecard — GSB review draft

Standalone HTML rendering of the 11-page Mycro-Tec Biology Battlecard
(Figma `RWiyqXmV33S3VddjniZrn4`, page `584:29`), built for Grant Kelson's review
ahead of moving the deck into the internal Live Dashboard "Resources" tool.

**Confidential — GSB / Hybrid Ag review draft. Not for grower distribution.**

- `index.html` — the whole document, single file, no build step. Seven tabs:
  Overview · SP · Digester · Lockout · Compare & verify · Measure & sample · Open with GSB
- `assets/` — 14 images exported from the Figma source (WebP, 1.4 MB total)
- `robots.txt` + `<meta name="robots" content="noindex">` — kept out of search

Copy is verbatim from the Figma master, but the 11 A4 pages were regrouped: each
product's "product play" and "field + sell" pages are one tab, since that split only
existed because a page ran out of room. Unresolved claims are marked *Open with GSB*
in place and collected in a 16-item register on the last tab.

Tabs are deep-linkable (`index.html#lockout`) and driven by `location.hash`.

Source extraction and the raw copy dump live in the sibling `extract/` folder
in OneDrive (not committed).
